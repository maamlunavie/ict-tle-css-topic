Learning Objectives

  • Use color names, HEX, RGB, and RGBA.
  • Create solid, gradient, and image backgrounds.
  • Apply readable fonts and text formatting.
  • Use margin, padding, and border correctly.
  • Style links, icons, lists, and tables.
  • Apply hover, focus, and active states.
  • Create smooth transitions.
  • Build a keyframe animation.

Essential Vocabulary

HEX
A color code using # and six hexadecimal characters.
RGB
A color made from red, green, and blue values.
RGBA
RGB with an alpha value for transparency.
Gradient
A smooth blend between colors.
Typography
The visual arrangement of fonts and text.
Contrast
The difference between foreground and background.
Margin
Space outside a border.
Padding
Space between content and border.
Transition
A smooth change between property values.
Animation
A sequence of stages defined by keyframes.

1. CSS Colors

CSS accepts several color formats. Choose colors with clear contrast and use a consistent palette.

#102a43
rgb()
gold
rgba()
h1 { color: navy; }
p { color: #176b87; }
.card { color: rgb(36,59,83); }
.overlay { background: rgba(0,0,0,.5); }
COLOR GUIDELINES
  • Use a limited palette.
  • Keep body text readable.
  • Do not rely on color alone.
  • Test foreground and background contrast.
Suggested palette: dark primary, bright accent, light background, and readable text color.

2. Background Properties

Solid

background-color:#f7f4ea;

Clean and readable.

Gradient

linear-gradient(...)

Smooth color blend.

Image

url("photo.jpg")

Places an image behind content.

.hero {
  background-image: url("school.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
Readability: Add an overlay when text appears over a detailed photo.

3. Fonts and Text Styling

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}
h1 {
  font-family: Georgia, serif;
  text-align: center;
  letter-spacing: 1px;
}
ACTUAL OUTPUT

Georgia for an expressive heading.

Arial for readable paragraphs.

4. Borders, Margin, and Padding

.box {
  margin: 20px;       /* outside */
  border: 5px solid #176b87;
  padding: 20px;      /* inside */
  border-radius: 12px;
}
Padding inside; margin outside.

Shorthand

margin: 10px 20px 30px 40px;
/* top, right, bottom, left */

padding: 15px 25px;
/* top/bottom, left/right */
Memory guide: Margin separates boxes; padding gives content breathing room.

5. Links and Icons

a:link { color:#176b87; }
a:visited { color:#6a4c93; }
a:hover { color:#b04b19; }
a:active { color:#d62828; }
a:focus { outline:3px solid #ffd166; }

Icons may use image files, SVG, libraries, or Unicode symbols such as ★, ✓, and →. Meaningful image icons need alternative text.

User experience: Hover and keyboard-focus states show that a link is interactive.

PartRecommended Style

Table headingsStrong contrast and bold labels.
Table cellsComfortable padding and clear borders.
Long tableAlternating rows and horizontal scrolling.

7. Transition and Animation

.button {
  transition:transform .25s,
             background .25s;
}
.button:hover {
  transform:translateY(-5px);
  background:#b04b19;
}

Keyframes

@keyframes pulse {
  0%,100% { transform:scale(1); }
  50% { transform:scale(1.15); }
}
.square { animation:pulse 2s infinite; }
Motion rule: Animation should guide attention, not distract users.
