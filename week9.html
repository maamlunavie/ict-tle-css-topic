Essential Vocabulary

Content
The text, image, or material inside an element.
Padding
Space between content and border.
Border
The visible edge around an element.
Margin
Space outside the border.
Content-box
Width applies only to content.
Border-box
Width includes padding and border.
Overflow
Content extending beyond set dimensions.
Blur Radius
Controls shadow softness.
Spread Radius
Expands or contracts a shadow.
Transform
Changes visual position, size, or angle.
Transform Origin
The point around which a transform occurs.

1. The CSS Box Model

Four Layers

  1. Content – text or image.
  2. Padding – inner space.
  3. Border – visible edge.
  4. Margin – outer space.

Why It Matters

  • Controls spacing.
  • Prevents crowded layouts.
  • Affects total size.
  • Helps align cards.
.box {
  width:300px;
  margin:20px;
  border:8px solid #176b87;
  padding:25px;
}
Content inside padding and border

2. Element Sizing and Calculation

Content-box Calculation

Content width: 300px
Left/right padding: 20px + 20px
Left/right border: 2px + 2px

300 + 20 + 20 + 2 + 2 = 344px total width

Border-box

* { box-sizing:border-box; }
.box {
  width:300px;
  /* content + padding + border = 300px */
}
PropertyPurpose
width / heightSets a specific size.
min-width / min-heightPrevents an element from becoming too small.
max-width / max-heightPrevents an element from becoming too large.
box-sizingControls which layers are included in the size.
Recommended: Use * { box-sizing:border-box; }.

3. Managing Overflow

Overflow occurs when content is larger than its container.

ValueEffect
visibleContent extends outside; default behavior.
hiddenExtra content is clipped.
scrollScrollbars always appear.
autoScrollbars appear only when needed.
.table-container {
  max-width:100%;
  overflow-x:auto;
}
Avoid: Fixed heights may cut off paragraph text.

4. CSS Box Shadow

box-shadow: horizontal vertical blur spread color;
.card {
  box-shadow:
    0 16px 30px 0
    rgba(16,42,67,.22);
}
A subtle shadow adds depth.

Shadow Parts

  • Horizontal offset: positive moves right.
  • Vertical offset: positive moves down.
  • Blur radius: softens the shadow.
  • Spread radius: changes shadow size.
  • RGBA: provides transparent color.
  • inset: places shadow inside.
box-shadow:inset 0 0 10px rgba(0,0,0,.2);

6. Combining Transform and Transition

.card {
  transition:transform .3s ease,
             box-shadow .3s ease;
}
.card:hover {
  transform:translateY(-8px);
  box-shadow:0 18px 35px rgba(0,0,0,.18);
}

transform defines the change. transition controls how smoothly the change happens.

Performance: Transform and opacity usually animate more smoothly than width, height, or margin.

7. Common Errors and Solutions

ProblemBetter Practice
Cards are wider than expected.Use border-box.
Text is cut off.Remove fixed height or use overflow.
Shadow looks heavy.Use transparent RGBA and moderate blur.
Scaled card overlaps.Use smaller scale and more gap.
Movement is sudden.Add transition to normal state.
Transforms replace one another.Write functions in one declaration.
