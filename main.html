WEEK 7

CSS Syntax and Selectors

CSS controls the appearance of HTML elements. A rule contains a selector, a property, and a value.

p { color: #173c36; }

The selector p targets paragraphs, color is the property, and #173c36 is the value.

Selector Guide

  • Element: h1, p, table
  • Class: .button, reusable on many elements
  • ID: #about, used for one unique element
  • Pseudo-class: a:hover, styles a special state
