Essential Vocabulary

CSS
Cascading Style Sheets; controls webpage presentation.
Rule Set
A selector plus a declaration block.
Selector
The pattern that identifies elements to style.
Property
The design feature being changed.
Value
The setting assigned to a property.
Declaration
A property-and-value pair ending with a semicolon.
Cascade
The process used to decide which competing rule applies.
Inheritance
When a child receives certain styles from its parent.
Specificity
The strength or priority of a selector.
Pseudo-class
A selector for a special state such as :hover.

Creates headings, paragraphs, links, forms, lists, and tables.Controls colors, fonts, backgrounds, spacing, layout, and effects.

Remember: HTML is the structure; CSS is the presentation.

2. CSS Syntax

selector { property: value; }
p {
  color: #176b87;
  font-size: 18px;
}
ACTUAL OUTPUT

This paragraph uses an element selector.

Parts of the Rule

  • p is the selector.
  • color and font-size are properties.
  • #176b87 and 18px are values.
  • A colon separates property and value.
  • A semicolon ends each declaration.
  • Curly braces contain the declarations.

CSS Comments

/* This comment explains the next rule. */
h1 { color: navy; }

3. Important CSS Selectors

Element

p { }

Targets every matching tag.

Class

.highlight { }

Reusable on many elements.

ID

#unique { }

Targets one unique element.

Universal

* { }

Targets all elements.

Grouped

h1, h2, p { }

One rule for several selectors.

Pseudo-class

a:hover { }

Targets a special state.

Descendant and Child Selectors

nav a { color: white; }       /* Any link inside nav */
nav > a { font-weight: bold; } /* Direct child link */

5. Cascade, Inheritance, and Specificity

Cascade

When rules have equal strength, the later rule normally wins.

p { color: blue; }
p { color: green; } /* wins */

Inheritance

Some styles such as color and font-family pass from parent to child.

body {
  color: #243b53;
  font-family: Arial;
}

Basic Specificity

Inline style > ID > Class / pseudo-class > Element

Avoid overusing !important: it makes CSS harder to correct and maintain.
